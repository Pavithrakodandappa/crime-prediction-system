Project Development Timeline
Phase 01
Problem Definition & Literature Review
Reviewed 24 papers on predictive policing. Defined scope, objectives, dataset requirements. Selected Random Forest and LSTM as primary candidates.
Phase 02
Data Collection & Preprocessing
Acquired 12,847 records from city crime DB (2019–2024). Cleaned missing values, removed outliers, standardized formats across 48 features.
Phase 03
EDA & Feature Engineering
Full EDA: correlation matrices, temporal patterns, spatial clustering. Key finding: time-of-day and population density are dominant predictors.
Phase 04
Model Training & Evaluation
Trained 5 ML models. Random Forest (n=200) achieved 94.2% accuracy, F1=0.941. Hyperparameters tuned via GridSearchCV with 10-fold CV.
Phase 05
System Development
Built Flask REST API, interactive dashboard, KDE heatmap generator. Integrated all modules into unified prediction system.
Phase 06
Deployment & Documentation
Deployed on AWS EC2 + Docker. Final testing, performance benchmarking, project report, and guide presentation.
Core ML Code — Random Forest Classifier
# crime_classifier.py — Core ML Module import pandas as pd import numpy as np from sklearn.ensemble import RandomForestClassifier from sklearn.preprocessing import MinMaxScaler from sklearn.model_selection import cross_val_score, GridSearchCV from imblearn.over_sampling import SMOTE # Load & preprocess df = pd.read_csv('crime_data_2019_2024.csv') df['hour'] = pd.to_datetime(df['timestamp']).dt.hour df['dayofweek'] = pd.to_datetime(df['timestamp']).dt.dayofweek df['is_night'] = (df['hour'] >= 20) | (df['hour'] <= 6) df['is_weekend'] = df['dayofweek'] >= 5 FEATURES = ['area_name', 'hour', 'dayofweek', 'is_night', 'is_weekend', 'population_density', 'dist_to_station', 'prior_incidents_30d', 'weather_code', 'lighting_index'] X = df[FEATURES] y = df['crime_type'] # Handle class imbalance sm = SMOTE(random_state=42) X_res, y_res = sm.fit_resample(X, y) # Scale features scaler = MinMaxScaler() X_scaled = scaler.fit_transform(X_res) # Train best model model = RandomForestClassifier( n_estimators=200, max_depth=18, min_samples_split=4, random_state=42 ) scores = cross_val_score(model, X_scaled, y_res, cv=10) print(f"CV Accuracy: {scores.mean():.3f} ± {scores.std():.3f}") # Output: CV Accuracy: 0.938 ± 0.012
